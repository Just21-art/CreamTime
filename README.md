# CreamTime
CreamTime-хоррор 3D/Part 1
Данный проект был анонсирован разработчиком Just21-art (25.10.2026).Игра ещё не выпущена,и находится в разработке.
Creamtime-это хоррор игра,где игроку надо исследовать глубины фабрики,говорят что после распада СССР в 1992 году монстры,те самые эксперименты сладости начали час радости,фабрику закрыли,а игрок спустя 15 лет возвращается на эту фабрику что бы узнать что произошло,но тут игрока встречает один из охранников,высокий и не очень дружелюбный монстр...
